# Session log — 2026-07-27 — M2

Edge extraction + adjacency + classification for the fillet operator. Grows
`GeometryEvaluator::visit(FilletNode)` from a no-op into a mesh-inspecting pass
that classifies every edge and logs diagnostic counts. Still emits **no tool
geometry** — output is unchanged (empty) from M0/M1.

## What was built

### Edge classification core
- New `src/geometry/fillet/FilletBuilder.{h,cc}`: `buildFilletTool(node, target)`.
  - Pulls the target's `MeshGL64` (`getManifold().GetMeshGL64()`).
  - **Merges MeshGL vertices by exact position** — MeshGL emits a vertex once
    per run it touches, so raw indices don't give topology until coincident
    positions are unified.
  - Builds triangles with outward normals and per-triangle source id (run walk,
    mirroring `ManifoldGeometry::toPolySet`).
  - **Rebuilds edge → two-face adjacency** from the triangle soup (undirected
    vertex-pair keys). Reports any non-two-face edges (0 on a manifold).
  - Classifies each edge:
    - **Angle filter** (primary accept/reject): keep creases `>= 1.5 ×
      max($fa, 360/$fn)`; `min_angle=` overrides. Rejects tessellation seams,
      including our own future arc seams.
    - **Concave/convex** via the far-vertex test (does A's far corner poke in
      front of B's plane) — order-independent, unlike `dot(nA, nB)` alone.
    - **Provenance** (same source id) is computed and **logged as a diagnostic**,
      not used to override the angle test (see decision below).
  - Emits one `ECHO` line of counts; returns `nullptr` (no geometry yet).
- New `CurveDiscretizer::getMaxSeamAngle()` — the largest circular-seam dihedral
  the discretizer can emit, feeding the angle threshold.
- Wired into `GeometryEvaluator::visit(FilletNode)`: collects children, converts
  child 0 via `ManifoldUtils::createManifoldFromGeometry` (guarded by
  `ENABLE_MANIFOLD`), calls `buildFilletTool`. `CMakeLists.txt` adds the source
  under `MANIFOLD_SOURCES`.

## Key decisions

- **Angle filter is the sole accept/reject; provenance is only reported.** A hard
  same-id `skip` wrongly drops a primitive's own sharp edges once it is unioned
  with anything (an L built from two cubes loses its outer edges — each edge's
  two faces share that cube's id). Same-id-but-sharp and same-id-coarse-curved-
  seam are indistinguishable by id alone, so provenance can't gate without
  curvature analysis. The `same-surface` count is logged for later use.
- **"6 faces" in the plan was loose wording.** MeshGL `originalID` is per source
  *primitive*, not per geometric face — a lone cube is **1** surface. The
  meaningful acceptance count (12 feature edges, all convex) holds.
- **One computation, both paths.** Render and preview both reach the same
  `visit(FilletNode)`, so the `ECHO` line appears identically in each (cached, so
  it re-fires only on a cache miss).
