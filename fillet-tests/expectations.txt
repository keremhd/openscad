# The two pocket cases used to segfault here, and it was not a fillet bug: the
# pocket's apex sat exactly in the plane of the block's top face, so the model
# pinched to a point at that vertex, and CGAL's convex decomposition — which
# every dilation goes through — dies on such a vertex. Reproducible in eight
# lines with no fillet node present, and unrelated to the pocket's face count:
#
#   minkowski() {
#     difference() {
#       translate([-30,-30,0]) cube([60,60,60]);
#       cylinder(r1 = 30, r2 = 0, h = 60, $fn = 3);   // apex at z = 60
#     }
#     cube(12, center = true);
#   }
#
# Move the apex a millimetre either way and it is clean, so the cases now leave
# material above it (CAP) and the crash is gone for good. What is left is a
# statement about the fillet: with no junction cells the chains run to the
# meeting point and pile up there, and the applied result is not a solid CGAL
# will dilate. The corner milestone is what turns these green.
case_junction3_pocket   *  sandwich  FAIL
case_junction4_pocket   *  sandwich  FAIL
